# UI 重设计 — 统一 LoRA Hub 面板

**日期:** 2026-05-21
**状态:** 待审批
**范围:** 前端重构（JS + CSS），后端 API 不变

---

## 问题诊断

当前 UI 的核心痛点：

1. **画布 widget 太挤** — 300px 宽度塞了权重输入、开关、✎ 按钮、删除按钮，交互极其局促
2. **群组管理藏太深** — 点击 grid 图标 → 下拉菜单 → "管理群组" 才能进入
3. **Prompt 编辑器太小** — ✎ 按钮弹出的浮窗窄小，用 `prompt()` 弹窗编辑 prompt 体，体验极差
4. **LoRA 磁盘浏览被困在群组内部** — 只能在编辑群组时逐个添加，不能全局浏览
5. **两个 UI 表面脱节** — 画布 widget 和管理面板是两套独立逻辑

## 设计理念：LoRA Hub

**核心原则：LoRA 优先，一切从磁盘出发。**

画布节点变成一个紧凑的**摘要条**，一个按钮打开**统一管理面板（LoRA Hub）**。Hub 内所有操作在一个全屏面板内完成。

## 详细设计

### 1. 画布 Widget（精简）

**文件:** `canvas_widget.js`（重写）

画布上的 widget 只做两件事：显示摘要 + 入口。

```
┌──────────────────────────────┐
│ LoRA Stack ▾          [3/5]  │  ← 标题 + 启用数/总数
│ ┌──────────────────────────┐ │
│ │ ☑ flat_style    0.8/0.8  │ │  ← 栈项：开关 + 名称 + 权重
│ │ ☑ detail_v2     1.0/1.0  │ │
│ │ ☐ anime_mix     0.5/0.5  │ │  ← 灰色 = 禁用
│ │ ▪ "人物精修" 组 (4 LoRA)  │ │  ← 群组引用：紫色标识
│ └──────────────────────────┘ │
│ [+ 添加]  [⚙ LoRA Hub]      │  ← 两个按钮，大而醒目
└──────────────────────────────┘
```

- 最小宽度 280px，最大宽度自适应节点
- 栈项只有三列：开关 | 名称 | 权重（去掉 grip、✎、删除）
- "+ 添加" 打开一个简单的搜索下拉（从磁盘添加 LoRA 到栈）
- "⚙ LoRA Hub" 打开统一管理面板
- 群组引用项点击可直接打开 Hub 并定位到该群组
- 右键菜单保留：管理 LoRA Hub、刷新栈、清空栈

### 2. LoRA Hub — 统一管理面板

**新文件:** `hub_panel.js`（替代 `group_panel.js` + `lora_browser.js`）

**结构：**

#### 左侧面板 — 浏览与选择

两种 Tab 切换：

**Tab A: LoRA 磁盘浏览器（默认）**
```
┌─────────────────────┐
│   [LoRA] [群组]      │  ← Tab 切换
├─────────────────────┤
│  搜索...          │  ← 模糊搜索
├─────────────────────┤
│  ▸ models/          │  ← 文件夹树
│    ▸ character/     │
│      flat_style     │  ← LoRA 文件（带标签）
│      detail_v2      │
│    ▸ style/         │
│      anime_mix      │
│  ▸ lycoris/         │
│    ...              │
└─────────────────────┘
```

- 文件夹树 + 模糊搜索（复用现有 `lora_scan` API）
- 每个 LoRA 旁显示小标签：已配置 prompt 的显示 ✎，属于某个群组的显示群组数
- 点击 LoRA → 右侧面板显示详情

**Tab B: 群组列表**
```
┌─────────────────────┐
│   [LoRA] [群组]      │
├─────────────────────┤
│  [+] 新建群组        │
├─────────────────────┤
│  人物精修 (4)        │
│  风景增强 (2)        │
│  通用优化 (6)        │
└─────────────────────┘
```

- 群组列表 + 新建按钮
- 点击群组 → 右侧面板显示群组内容

#### 右侧面板 — 详情编辑

**视图 A: LoRA 详情（从左侧 LoRA Tab 点击）**
```
┌──────────────────────────────────────┐
│ flat_style.safetensors               │  ← 文件名
│ models/character/                    │  ← 路径
│                                      │
│ ── Prompt 组 ──────────────────────  │  ← 内联编辑！
│                                      │
│ ┌─ 组: 基础效果 ──────────────────┐  │
│ │ 正面:                          │  │
│ │ ┌────────────────────────────┐ │  │
│ │ │ detailed face, high quality│ │  │  ← textarea，可多行
│ │ └────────────────────────────┘ │  │
│ │ 负面:                          │  │
│ │ ┌────────────────────────────┐ │  │
│ │ │ blurry, low quality        │ │  │
│ │ └────────────────────────────┘ │  │
│ │            [保存] [删除组]      │  │
│ └────────────────────────────────┘  │
│                                      │
│ [+ 新建 Prompt 组]                   │
│                                      │
│ ── 所属群组 ──────────────────────  │
│  人物精修  风景增强                   │  ← 只读，点击跳转
│                                      │
│ ── 添加到群组 ────────────────────  │
│  [选择群组 ▾] [添加]                 │  ← 快速加入群组
│                                      │
│ [+ 添加到当前栈]                     │  ← 一键加到画布栈
└──────────────────────────────────────┘
```

**关键变化：Prompt 编辑是内联 textarea，不再用 `prompt()` 弹窗！**

**视图 B: 群组详情（从左侧群组 Tab 点击）**
```
┌──────────────────────────────────────┐
│ 人物精修                              │  ← 群组名 [✎] [导出]
│ 4 LoRA · 点击查看详情                  │
│                                      │
│ ┌──────────────────────────────────┐ │
│ │ ☑ flat_style      0.80 / 0.80   │ │  ← 拖拽排序
│ │ ☑ detail_v2       1.00 / 1.00   │ │
│ │ ☑ skin_smooth     0.60 / 0.60   │ │
│ │ ☑ eye_enhance     1.00 / 1.00   │ │
│ └──────────────────────────────────┘ │
│                                      │
│ [+ 从磁盘添加 LoRA]                  │  ← 展开左侧浏览器
│                                      │
│ [删除群组]                           │
└──────────────────────────────────────┘
```

- 从磁盘添加时，左侧 Tab 自动切到 LoRA 浏览器，点哪个就加哪个
- 权重输入比画布上大得多，用 slider + number 双控件

### 3. 交互流程

**流程 1：浏览 LoRA → 编辑 Prompt → 加入栈**
1. 点击画布节点上的 "⚙ LoRA Hub"
2. 默认显示 LoRA 浏览器 Tab，搜索找到目标 LoRA
3. 点击 LoRA → 右侧显示详情，编辑 prompt 组
4. 点击 "添加到当前栈" → 返回画布，栈已更新

**流程 2：创建群组 → 添加 LoRA → 使用群组**
1. 打开 Hub → 切换到群组 Tab → 新建群组
2. 右侧显示空群组 → 点击 "从磁盘添加"
3. 左侧切回 LoRA 浏览器，点击 LoRA 逐个添加
4. 完成后关闭 Hub，画布上通过 "+ 添加" 选择该群组引用

**流程 3：快速添加 LoRA 到栈（不进入 Hub）**
1. 直接在画布节点点击 "+ 添加"
2. 弹出搜索下拉（比当前更大，250px 宽）
3. 搜索 → 点击 → 立即加入栈

## 技术方案

### 文件变更清单

| 文件 | 操作 | 说明 |
|------|------|------|
| `hub_panel.js` | **新建** | 统一面板，替代 group_panel + lora_browser |
| `canvas_widget.js` | **重写** | 精简为摘要条 + 两个按钮 |
| `styles.css` | **大幅重写** | 删除 lgm-* 和 lsw-pe-* 旧样式，新增 lhub-* 样式 |
| `group_panel.js` | **删除** | 功能合并到 hub_panel.js |
| `lora_browser.js` | **删除** | 功能合并到 hub_panel.js |
| `index.js` | **修改** | 更新导入和右键菜单 |
| `api.js` | **不改** | API 层不变 |
| `stack_api.js` | **微调** | 可能需要小改 |

### CSS 命名规范

新样式统一使用 `lhub-` 前缀（LoRA Hub）：
- `.lhub-backdrop` — 背景遮罩
- `.lhub-modal` — 主面板容器
- `.lhub-header` — 标题栏
- `.lhub-sidebar` — 左侧面板
- `.lhub-content` — 右侧面板
- `.lhub-lora-*` — LoRA 相关
- `.lhub-group-*` — 群组相关
- `.lhub-prompt-*` — Prompt 编辑相关
- `.lsw-compact` — 精简画布 widget（保留 lsw- 前缀但大幅简化）

画布 widget 样式保留 `lsw-` 前缀但删除大部分旧样式。

### API 使用

完全复用现有 API，不新增后端端点：
- `lora_scan/*` — LoRA 磁盘浏览
- `lora_groups/*` — 群组 CRUD
- `lora_prompts/*` — Prompt 组 CRUD

### 数据流

```
画布 Widget ←→ stack_api.js ←→ hidden widget (lora_stack_data)
     ↓
  Hub Panel ←→ api.js ←→ backend API
     ↓
  (Hub 关闭时刷新画布 widget)
```

## 设计差异化

与旧版相比的核心差异：

| 维度 | 旧版 | 新版 |
|------|------|------|
| 入口 | 画布上直接操作 | 画布摘要 → 一键打开 Hub |
| LoRA 浏览 | 只能在群组内浏览 | 全局磁盘浏览，独立 Tab |
| Prompt 编辑 | 浮窗 + `prompt()` 弹窗 | 内联 textarea，完整编辑 |
| 群组管理 | 独立 modal，藏在下拉里 | Hub 内 Tab，随时可达 |
| 交互密度 | 300px 塞一切 | 全屏面板，从容操作 |
| 数据视角 | 以群组为中心 | 以 LoRA 为中心 |
