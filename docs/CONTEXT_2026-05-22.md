## 核心架构

### 节点注册模式（__init__.py）
```python
try:
    from .xxx import Xxx
    NODE_CLASS_MAPPINGS["Xxx"] = Xxx
    NODE_DISPLAY_NAME_MAPPINGS["Xxx"] = "显示名"
except ImportError as e:
    print(f"[PromptCraft] Warning: ...")
```

### 前端扩展模式
- `WEB_DIRECTORY = "js"` — ComfyUI 自动加载 js/ 目录
- `js/index.js` 是入口，import 各子模块
- 子模块在 `js/xxx/index.js`，通过 `app.registerExtension()` 注册
- LoRA 栈 UI 由 `js/lora_group/canvas_widget.js` 的 `initCanvasWidget(node)` 提供
- 栈数据通过隐藏 widget `lora_stack_data` (STRING) 从前端传到后端

### LoRA 栈数据流
```
前端 UI → StackAPI.serialize() → lora_stack_data widget (JSON string)
  → 后端 json.loads() → _flatten_stack() → comfy.sd.load_lora_for_models()
```

### LoRA Prompt 数据格式
```json
{
  "lora_path": {
    "groups": [
      { "name": "组名", "prompts": ["tag1", "tag2"], "negative": "neg" }
    ]
  }
}
```
获取方式: `lora_prompt_manager.get_all_for_stack(lora_paths, selected_groups)`

## 用户推荐工作流

```
CheckpointLoader ──→ clip ──→ CLIPTextEncodePro ──→ KSampler
                              ↑ clip
                              ↑ lora_text
LoraPromptLoader ──→ positive_text ─┘
  (checkpoint="None"，只用 LoRA 栈 + 输出文本)
```
- 标准 CheckpointLoader 负责底模
- LoraPromptLoader 只管理 LoRA 栈，输出 prompt 文本
- CLIPTextEncodePro 合并 lora_text + text，编码后送 KSampler
