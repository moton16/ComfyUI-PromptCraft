# PromptCraft 使用帮助

## 简介

PromptCraft 是一个功能丰富的 ComfyUI 提示词增强节点，支持内置库随机选择 + LLM 细节补充。

## 核心功能

### 提示词增强器 (PromptEnhancer)

- **内置提示词库**：支持 SFW / NSFW 两种提示词库，涵盖场景、动作、服饰、表情等多个分类
- **随机选择**：每个分类支持全量随机、仅 SFW 随机、仅 NSFW 随机三种模式
- **LLM 扩写**：接入大语言模型，支持基础扩写、详细扩写、普通扩写三种模式
- **负面提示词**：内置负面提示词库，支持随机选择或自定义

### LoRA 管理

- **LoRA Hub**：集中管理 LoRA 文件，支持搜索、收藏、分组
- **LoRA 栈**：在画布节点上直接管理 LoRA 加载顺序和权重
- **群组引用**：将多个 LoRA 组合为群组，一键应用

### 提示词工具

- **规则管理器**：设置 SFW / NSFW 增强规则
- **库编辑器**：编辑提示词库的分类和选项
- **提示词历史**：查看和复用历史提示词

## 快速上手

1. 在画布上添加 **PromptCraft** 节点
2. 在 **用户 Prompt** 输入框中输入基础提示词
3. 各分类下拉菜单选择具体标签或随机模式
4. 如需 LLM 扩写，先在设置面板配置 API 服务，然后开启 **语言大模型接入**
5. 连接正面/负面提示词输出到后续节点

## 设置面板

点击 ComfyUI 右上角齿轮图标 → 找到 **PromptCraft** 分组：

- **语言切换**：支持中文 / English
- **API 服务配置**：管理 LLM 服务接入
- **浮动面板**：开启/关闭右下角快捷面板
- **提示词工具**：规则管理器、库编辑器、历史记录

## 常见问题

**Q: 提示词库不生效？**
A: 修改库内容后，点击设置面板中的「重载缓存」按钮。

**Q: LLM 扩写无响应？**
A: 检查 API 服务配置中的端点 URL 和 API Key 是否正确，可使用「测试连接」按钮验证。

**Q: 如何添加自定义提示词？**
A: 使用设置面板中的「库编辑器」，可直接编辑 SFW / NSFW 库的分类和选项。
